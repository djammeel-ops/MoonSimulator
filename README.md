# محاكي الشمس والأرض والقمر

تطبيق ويب تفاعلي لعرض حركة الشمس والأرض والقمر وأطوار القمر.

## التشغيل
افتح `index.html` في متصفح حديث متصل بالإنترنت لتحميل مكتبة Three.js من CDN. يمكن نشر المستودع مباشرة عبر GitHub Pages.

## التحكم
- اسحب بإصبع واحد لتدوير المشهد.
- استخدم إصبعين للتكبير والتحريك.
- اختر أحد أوضاع العرض الثلاثة من الأعلى.
- استخدم شريط الأيام أو رموز الأطوار للانتقال خلال الشهر القمري.
- أزرار التشغيل والإيقاف والسرعة تتحكم في مرور الزمن.
- لوحة الإضاءة تسمح بضبط سطوع الشمس والأرض والقمر والإضاءة المحيطية بشكل مستقل.
- إعادة الضبط تعيد قيم الإضاءة الافتراضية.

## ملاحظات علمية
المسافات والأحجام في العرض توضيحية وليست بمقياس حقيقي. المحاكاة مبسطة، ومدار القمر مرسوم في مستوى واحد تقريباً. أطوار القمر تنتج عن تغير الجزء المضاء الذي نراه من الأرض، ولا تنتج عادةً عن ظل الأرض.

## ملاحظة تقنية
يحتاج التطبيق إلى اتصال بالإنترنت لتحميل Three.js من cdnjs.
